# 技術メモ: 基準寸法と参考資料

このゲームで印刷する対象は、**一層（平屋）・単ビード壁の小型庭園シェルター / 実証パビリオン壁体**。
巨大高層建築や「印刷直後に住める完成住宅」は描かない。印刷後に作業員の安全確認と、
閉曲線の場合のみプレキャスト屋根パネルのクレーン設置（別工程）を見せる。

## 採用寸法（架空機 GP-6 ガーデンプリンター）

| 項目 | 値 | 根拠 |
|---|---|---|
| ビード幅 | 60 mm | BOD2系のノズルは押出幅 20–100 mm（標準レイヤ幅 30–300 mm）。単ビード壁の実例は約50 mm幅 |
| 層高 | 20 mm | BOD2系のレイヤ高 5–40 mm の中庸。実例: 高さ2 m ≒ 100層 |
| 壁高 | 1.8 m（90層） | 庭園シェルター壁体として妥当。ベンチは 0.52 m（26層） |
| ノズル内径 | 32 mm | 丸口ノズル。骨材最大 10 mm を通せる径 |
| 定常ノズル速度 | 300 mm/s | 有人現場での実機上限 250 mm/s 前後（無柵時 1000 mm/s）。演出上わずかに上回る値 |
| 最小旋回半径（中心線） | 220 mm | ビード幅60 mmで自己重なりを避けつつ子どもの角を成立させる値 |
| 基礎スラブ | 5.2 × 5.2 m・厚150 mm | 建築可能範囲 3.8 × 3.8 m + 機械側余裕 |
| レール間隔 / 長さ | 6.6 m / 8.8 m | BOD2系のモジュール式ガントリー（約2.5 mモジュール）に整合 |
| 梁下クリアランス | 3.05 m | 壁高1.8 m + ヘッド長 + 余裕 |

## 機械構成（特定メーカーの複製ではない架空機）

- 地面に固定された左右レール（コンクリート基礎帯 + ボルト固定）
- レール上を Z 方向へ走行する門型フレーム（ラチス柱・車輪・走行モーター）
- 柱に沿って昇降するトラス梁（層高に追従）
- 梁上を X 方向へ走行するキャリッジとプリントヘッド（ホッパー・押出モーター・丸口ノズル）
- 材料ホース（ポンプ→地面→柱→梁上エネルギーチェーン→ヘッド）
- エネルギーチェーン（ケーブルキャリア、全長一定のU折返し）
- 近接する材料サイロ / バッチング・ミキシング装置 / 圧送ポンプ
- 成人作業員2名と仮設フェンス（安全柵）・警告縞

軸は X / Y(昇降) / Z の3軸のみ。ノズルは丸口のため旋回不要で、
角では送り速度計画（前後パスの台形速度計画）により機械的に減速する。
瞬間旋回・空中自由飛行はしない。

## 印刷の時間設計

- 第1層: ほぼ実時間（実機速度の約1.7倍再生）。ノズル・湿潤ビード・床の墨出し線を接写。
- 第2–3層: 短い追従（約4.5倍）で「同じ形が積み重なる」ことを見せる。
- 残層: 数秒のタイムラプス（約230倍）。見せ場の角・開放端では約9倍まで戻して減速を見せる。
- 層替わりは実機のZシーム相当（端部テーパー + 小さなリフト）。
