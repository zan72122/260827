# くるくる・ポッポ・チリン　クリスマス機構工房

冬の夕方、雪の村の小さな木工房。静かで暗いその部屋に、
**煙 → 回転 → 光 → 鐘の音** を、子どもが一台ずつ足していくモバイルWebゲームです。

対象：4歳児 ／ 端末：iPhone・iPad（縦横両対応）／ 文字を読めなくても遊べます。

---

## 起動方法

```bash
npm install
npm run dev        # http://localhost:5173 を開く
```

その他のコマンド:

```bash
npm run typecheck  # tsc --noEmit
npm run build      # 型検査 + 本番ビルド (dist/)
npm run preview    # ビルド結果をローカル配信
node scripts/autoplay.mjs            # 自動プレイ（横画面）＋スクリーンショット
node scripts/autoplay.mjs --portrait # 縦画面で自動プレイ
node scripts/autoplay.mjs --rotate   # 途中で画面を回転させて状態保持を確認
```

技術構成：Vite + TypeScript + Three.js（WebGL2）。
外部アセットなし。テクスチャ・音・形状はすべて実行時に生成しています。
広告・課金・ログイン・外部通信・録音済み音源は一切ありません。

## 遊びの流れ（一続きの体験）

メニューはありません。ひとつの部屋が、少しずつ動き出します。

### 1. 煙出し人形（そこに、けむりの道がある）
1. 上半身を上へスワイプ → 胴体が外れる
2. 一時的な断面表示で、**内部の空洞から口へ続く煙道**が見える
3. 香の円錐を、下半身中央の真鍮の受け皿へ置く
4. 大人用の長い点火具を近づけて火をつける
5. 上半身を下へ戻す → 少し間があって、**口から**細い煙が立ちのぼる

人形は本当に中空です（内壁と煙道を実ジオメトリで持っています）。
煙は口の一点からのみ出ます。

### 2. クリスマスピラミッド（下の火が、上の羽根を回す）
軸 → 回転台 → 人形3体 → ローター → 羽根6枚 → 羽根角度 → ろうそく4本 → 点火。

点火してもすぐには回りません。
**静止 → 小さく揺れる（静止摩擦） → ゆっくり一回転 → 安定速度**
という立ち上がりを、慣性・粘性抵抗・静止摩擦の簡易モデルで作っています。
羽根角度を変えると速度が変わり、逆向きにすれば逆回転しますが、
トルクが 0 になる「止まってしまう」状態は作れません。

火から羽根へは、**カットを割らずにカメラを上へ動かして**見せます。

### 3. エンジェルチャイム（羽根が回ると、鐘が鳴る）
天使3体を掛ける → 吊り位置を鐘の高さの目印に合わせる → 真鍮ベル5個を設置 → 点火。

鐘の音は音声ファイルの定期再生ではありません。
**ローターの実際の回転角と、天使のstrikerがベルの角度を横切った瞬間**に発音します。
速度が上がれば間隔は詰まり、遅くなればまばらになります。
ベルは5個・不等間隔配置・サイズ違い（音程違い）なので、
規則的なリズムにならず、偶然性のあるチリン、チリンになります。

### 4. 完成した部屋
作業台の接写からゆっくり引き、工房の電灯を一段落として終わります。
近景の煙、中景のピラミッドとチャイム、遠景の雪窓が同時に読める画になります。

そのあとは自由操作です。装置をタップ（または画面上部の3つの印をタップ）すると、
- 人形をもう一度開けて閉める
- 羽根の角度を変える
- ベルの組み合わせを変える

が、最初からやり直さずに何度でもできます。

## 操作

一本指だけです。細かい狙いは要りません。

| 動作 | 操作 |
|---|---|
| 上半身を外す／戻す | 上／下へスワイプ |
| 部品を取り付ける | ドラッグ（近づけば吸着）または**タップだけでも入る** |
| 羽根の角度 | 大きく横へスワイプ |
| 天使の吊り位置 | 大きく縦へスワイプ |
| 点火 | 点火具を太い軌道で動かし、芯の近くで少し止める |

迷って手が止まると、ゴーストハンドがその場の動作を実演します。
カメラは常に自動です（子どもに自由カメラは持たせません）。

## 実装メモ

- **材質**：木は板目・旋盤目・木口の3種を焼き分け、塗料は木地の上の薄い皮膜として、
  手が触れる帯に摩耗を置いています。真鍮は金色プラスチックではなく、
  拭かれて光る筋と鈍い酸化の斑を粗さマップで混ぜています。
- **照明**：影を落とす動的ライトは天井灯ひとつ。窓は冷たいフィル、
  ろうそくは装置ごとに1灯へまとめ、あとはemissiveと簡易環境マップ（PMREM）。
- **暖気**：魔法の光線は使いません。炎、上へ流される微細な埃、
  炎の上だけに限定したスクリーン空間の陽炎、煙の曲がり、
  そしてローターの始動順序で見せます。
- **煙**：数十枚のビルボードをCPUで進める細い糸。太い雲にはしません。
- **instancing**：羽根、ろうそく、削り屑、鑿、村の窓明かり。
- **音**：WebAudioのみ。鐘は非調和倍音のモーダル合成、
  火・風・軸鳴りはフィルタしたノイズ、成功音は短い5音音階。既存曲は使いません。
- **性能**：端末情報から3段階のtierを推定し、フレーム時間が持たなければ一段下げます
  （DPR・影・粒子数・陽炎）。タブ復帰でローターが飛ばないようdtを制限しています。
- **画面回転**：シーンは再生成されません。カメラ姿勢は縦横それぞれの値へ滑らかに寄り、
  部品トレイは縦画面では手前（画面下）へ移ります。点火状態・回転速度・煙・
  取り付け済みの部品はそのまま保持されます。

## 検証

`scripts/autoplay.mjs` は、暗い部屋から三台の起動、完成画面、再操作までを
**実際のポインタ入力**で通しで自動プレイします（座標はゴーストハンドと同じ
ヒント情報から取得します。この読み出し口は `?autotest` を付けたときだけ有効で、
通常の画面には現れません）。

確認済み:

- 横画面 1194×834 / 960×672、縦画面 672×960 で最初から最後まで完走
- 三台とも稼働（煙が出ている・ピラミッド回転中・チャイム回転中）
- 鐘の発音数は回転角から発生した実測値（1プレイで170回前後）
- 組み立て途中で画面を回転させても、点火状態・回転速度・煙・取り付け済み部品を
  そのまま保持し、残りの工程もそのまま遊べる
- 完成後、装置タップと画面上部の印から、人形の開閉・羽根角度・ベルの組合せを
  やり直せる
- `npm run typecheck` / `npm run build` が通る（JS 約690KB、gzip 約182KB）
- ページ例外 0 件

スクリーンショットは `shots/`（横）と `shots-portrait/`（縦）に出ます。

## 既知の制約

- **WebGL2 必須**です。WebGPU は使っていません（追加表現の予定枠のみ）。
  WebGL2 が無い端末には、その旨だけを表示します。
- **音は最初のタッチまで鳴りません**（iOS の自動再生制限のため）。
  音のオン・オフは右上のアイコンです。
- 検証環境は GPU の無いコンテナで、ソフトウェアラスタライザ（SwiftShader）です。
  フレームが持たないため実行中に性能tierが自動で一段下がり、
  添付スクリーンショットは影と陽炎を切った状態のものが混じります。
  実機の iPhone / iPad では mid / high の見た目になります。
- 工房は一部屋・一つの作業台だけです。村の探索、工房経営、収集要素はありません
  （意図的に入れていません）。
- 職人は中景のシルエットとして立っているだけで、会話や操作対象ではありません。
