# よいしょ！ ひろばの大きなクリスマスツリー

4歳児が iPhone / iPad の Safari で遊べる、3D の「巨大クリスマスツリー設置」ゲームです。
飾りつけゲームではなく、**12〜18 m の天然木を移動式クレーンで起こして、広場の受け口へ据え付ける工程そのもの**が主役です。

子どもが理解する一文：**「大きな木をクレーンで起こして、穴に入れて、光をつけた」**

## 工程（毎回この順番）

1. トレーラー到着（大きな矢印を横スワイプ）
2. クレーンのアウトリガー展開 → ジャッキ接地（4方向スワイプ＋下スワイプ）
3. 幹に幅広スリングを2本掛ける（色つきパックをドラッグ）
4. 水平の巨大木を垂直へ起こす（レバーを上へ／タグラインを左右へ）
5. 鋼製ソケットへ下ろす（レバーを下へ）
6. ガイワイヤーを張る（キャプスタンを円運動）
7. 高所作業車で光を螺旋状に巻く（螺旋ガイドをなぞる）→ 星を取り付ける
8. 町の一斉点灯（儀式用スイッチを下から上へ）

失敗・落下・事故・ゲームオーバーはありません。安全準備は飛ばせませんが、叱る表示も出ません。

## 動かす

```bash
npm install
npm run dev        # 開発サーバ（http://localhost:5173）
npm run typecheck  # 型検査のみ
npm run build      # 型検査 + 本番ビルド（dist/）
npm run preview    # dist を配信（http://localhost:4173）
```

iPhone / iPad の実機で試す場合は `npm run dev` の LAN アドレス（`--host` 有効）へアクセスしてください。

### URL パラメータ

| パラメータ | 説明 |
| --- | --- |
| `?auto=1` | 開始から点灯まで自動操作（検証用） |
| `?seed=12345` | 木の樹形・広場配置・天候・電球色・星の意匠を固定 |
| `?turbo=6` | 1フレームあたりの更新回数（ソフトウェアレンダラでの検証用。通常プレイでは 1） |

検証用フック：`window.__game.stage()`（現在の工程名）、`window.__game.state()`（工程状態の要約）、
`window.__game.auto()`（自動操作開始）、`window.__game.turbo(n)`。

## 技術メモ

- Vite + TypeScript + Three.js（WebGL2、追加ライブラリなし）
- 巨大木は「幹スプライン＋whorl 状の枝＋7 バンドの葉群」。葉はバンド単位で1メッシュに結合し、
  バンドごとのバネで幹の角加速度に遅れて追従します。LOD は近距離／遠距離の 2 段。
- クレーンはアウトリガー（伸縮ビーム＋2段ジャッキ＋接地板＋敷板）、
  3段テレスコピックブーム、幾何解で追従する起伏シリンダ、ドラム→ヘッド→フックのワイヤロープ。
- スリングは幹を貫通しない「チョーク掛け」のリボンジオメトリ。荷重で張り、シャックルでフックへ。
- 高所作業車は 2 リンク IK。バスケットは常に水平を保ちます。
- 電球は InstancedMesh（暗いガラス球＋点灯球の2セット）。コードは実ジオメトリの spline で、
  アンカー間にたるみがあります。動的 point light は 4 灯のみ。
- 建物窓・街路灯は emissive の InstancedMesh を順次点灯。
- 音は WebAudio による完全合成（録音素材なし）。初回タップ後に開始します。
- 端末階層（低／中／高）で DPR・影解像度・雪粒子数・住民数・木の枝密度を調整。
- タブ復帰時は dt をクランプし、物理時間が飛びません。`pointercancel` / 連打 / 画面回転に対応。
- 広告・課金・ログイン・分析 SDK は一切含みません。

## 検証

`tools/shoot.mjs` は Playwright で自動操作を走らせ、iPhone / iPad の縦横 4 ビューポートで
各工程のスクリーンショットを `shots/` に保存します。

```bash
npm run build
npm run preview &
node tools/shoot.mjs all              # 4ビューポート × 全工程のスクリーンショット
node tools/rotate-test.mjs            # 画面回転で工程状態が保たれるかを検証
```

`tools/rotate-test.mjs` は吊り上げ中と電飾中に縦横を切り替え、工程・木の角度・吊り具・
ガイワイヤー・電飾の進捗が保たれること、および操作要素が画面外へ出ないことを確認します。
