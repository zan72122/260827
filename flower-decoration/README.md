# はなかざり 🌸 — 会場装花3Dゲーム

4歳児向けの WebGL 3D ゲーム。パーティー会場をお花で飾りつけ、最後に大扉を開いてお披露目します。

**文字なし・失敗なし・一指操作・縦横対応。**

## あそびかた

光っているところをタップ（またはドラッグ）するだけ。

1. **お花えらび** — 3種類（バラ・チューリップ・デイジー）から1つタップ
2. **色えらび** — 4色（ピンク・黄・ラベンダー・水色）から1つタップ
3. **茎をそろえる** — 光るラインでチョキン。はさみが切ってくれます
4. **アーチに飾る** — 好きな場所をタップするとそこに花が生える。最低数を飾ると
   金の星ボタンが現れ、押すと次へ（好きなだけ追加OK）
5. **テーブル装花** — 好きな場所をタップするとそこに花が生える。最低数を飾ると
   金の星ボタンが現れ、押すと次へ（好きなだけ追加OK）
6. **つぼみを水へ** — つぼみをドラッグして花瓶の水に入れる（タップでもOK）
7. **リボンと吊り飾り** — 好きな場所をタップするとそこに吊り飾りが下がる。最低数を
   飾ると金の星ボタンが現れ、押すと次へ（好きなだけ追加OK）
   - フィナーレでは、プレイヤーが置いた花を中心に小さなまとまりが増えて咲く。
     ゲスト卓はプレイヤーが飾った卓の模様をコピーする。仕上げカットでは水に生けた
     花瓶がメインテーブルへ飛んでいく
8. **大扉オープン！** — 扉をタップすると左右に開き、光が差し込み、
   つぼみが一斉に開花。花のアーチ・吊り花・テーブル装花が現れ、
   花びらが舞うパーティー会場に変わります。成人スケールのゲスト48人（車椅子2人を含む）
   のうち36人は宴席に着き、残る12人が中央通路から入場して着席します。高砂には
   ピアノとバーには演奏者とバーテンダーが現れます。全員の着席後、新郎新婦が中央通路を
   入場して高砂へ到着し、続いて給仕がサービスレーンからグラスを運んで戻ります。その後、
   乾杯、拍手、歓談、会場を巡るカメラツアーへ進みます。花びらは一度だけ舞って床へ
   収束し、完成カードからもう一度遊べます。
   花はサイズ・種類・色にばらつきがあり、選んだ花と色が主役になります。通路には
   連続した花壇ではなく、間を空けた14基の床置き装花を配置します。ステージ4基と合わせた
   18クラスターには、花首だけでなく、見える茎、葉、花器、吸水フォームがあります。
   左右非対称のアーチ、高砂、低い卓上花とともに約3秒で順番に咲き広がります。

選んだ花の種類と色は、フィナーレの装花・リボン・花びらすべてに反映されます。
準備中は大扉と仕切りカーテンが閉じていて、会場の全体像は最後まで見えません。
施工装花は大扉を開くフィナーレでだけ自動的に現れるため、花・色の選択、自由配置、
最低配置数、星ボタンなど、それまでの操作手順と操作量は変わりません。
会場内装は、象牙色の絹ダマスク、金古美モール、鏡、磨き寄木、クリスタル、シフォンを
重ねた欧州ガーデン宮殿です。準備中から内装は存在し、フィナーレでは布が一度ふわりと
動いた後、壁灯、3基のシャンデリア、キャンドル、高砂の順に黄金色へ点灯します。左右6面の
窓は、壁を分割した実開口に45cmの見込み、枠、ガラス反射、簡略外景を備えています。

## 実行方法

ビルド不要。静的サーバで配信するだけです。

```sh
python3 -m http.server 8321
# → http://localhost:8321/index.html
```

## 技術メモ

- **Three.js (r170, vendored)** による透視投影・実ジオメトリ・遮蔽・視差のあるWebGL空間
- 実寸ベースの会場（ホール16×22m・天井7m・大扉4.4m・テーブル高0.74m）
- 花びらは種類ごとの `InstancedMesh` に集約し、開花（bloom 0〜1）を行列更新で連続アニメーション
- 近景・中景・遠景の分離＋フォグによる空気遠近、PCFソフトシャドウ、PMREM環境マップ
- 固定シードのヴェルサイユ寄木は床全体用の8×11セル・1024pxアトラスとして生成し、
  木目方向、色、継ぎ位置を崩す。ダマスク、ベルベット織りにも柔らかい反射・bump・
  roughness差を付ける
- 効果音・BGMはWebAudioでリアルタイム合成（外部アセットなし）。音楽・効果音・環境音の
  3バス、ホール残響、ピアノとバーの位置音源、歓談、食器、足音、衣擦れを分離する。
  画面右上の音量ボタンは状態とARIA属性を同期して切り替える
- マルチタッチは無視（一指操作のみ）。どこをタップしても失敗にならない
- 自由配置（レイキャスト・プロキシ）と星ボタンは `src/place.js`、バラエティ・株分けプランは `src/variety.js`、ゲストは `src/guests.js`
- フィナーレ装花は `src/garden-plan.js` の固定シードによる決定的な配置。中央通路に
  幅2.7mの安全帯を残し、ゲスト卓は半径0.28m・高さ0.25m以内に収める。P0版691点に
  相当した花材を432点へ37.5%減らし、主色70%・白〜クリーム20%・反対寄りアクセント10%へ
  固定する
- アジサイ状の花房・小花・ユーカリ状の葉に加え、18基の施工クラスターごとに茎、花器、
  吸水フォームを持たせる。補助要素は `src/garden-installation.js` の `InstancedMesh` に集約し、
  開花完了後は行列を更新しない
- 主役花と補助要素は必要数に20%の予備容量を加えて事前検証し、描画上限を超える
  プランはフィナーレ開始時に検出する。`window.__flower.decor` からゾーン別件数、
  完了状態、容量使用量、検証結果を読み取り専用で確認できる
- `src/party-layout.js` が16×22mの会場、6卓×8席、幅2.7mの中央通路、車椅子席2か所、
  通路花、卓上装花、高砂、小景の衝突余白を一元管理し、固定座標をNodeテストと実行時で共有する
- `src/palace-interior.js`が壁・床・天井・布・段階照明、`src/palace-tablescape.js`が
  48人分の宴席（Louis XVI風椅子46脚＋車椅子スペース2席）と高砂2席、合計50席の
  正式セッティングを担当する。全席に料理、パン、水、飲み物を加え、ケーキ卓とナイフ、
  作業域付きバー、黒鍵・ペダル・譜面台・椅子付きピアノ、利用中のラウンジ、卓番号と
  対応線のある席次板を備える。6卓の装花にもコンポート6、フォーム6、見える茎36本を置く。
  木、真鍮、磁器、銀、ガラス、飲料、布、紙、漆、鏡、料理の
  11素材クラス、家具の面取り、布の折り、接触影で近景の記号感を抑える。
  `src/celebration-characters.js`が新郎新婦・ピアニスト・バーテンダーを担当する
- `src/guests.js` は成人・子ども・高齢者を含む48人を8個の `InstancedMesh` に集約し、
  成人42人（うち高齢者6人）・子ども6人・車椅子利用者2人を成人家具に合う縮尺で描き、
  入場、着席、乾杯、拍手、歓談の状態を分けて更新する
- 給仕演出は右側サービスレーン内で往復し、衝突のない配膳完了後だけ乾杯へ進む。
  フィナーレの花びらは再生成せず、全460枚の着地後に描画数を0へ戻す
- 宴席、建築装飾、人物は反復部品をInstancedMeshへ集約する。小さなグラスと
  クリスタルはtransmissionを使わず、透明度と環境反射で会場全体の再描画を避ける
- `window.__flower.interior`から内装完成、照明段階、布の静止、宴席・人物・描画統計を
  読み取り専用で確認できる

## 検証

`tools/verify.mjs` が Playwright で全フェーズを自動プレイし、
各段階のスクリーンショット、コンソールエラー、庭園装花と宮殿内装の完了状態・容量を確認します。
横・縦画面のフィナーレでは、通路とアーチの密度、人物や家具を隠さない低い卓上花、
48人の着席と車椅子席、給仕・乾杯・拍手・歓談、花びらの収束、
カメラツアー完了後の完成カードとリプレイ表示、
6実窓・3シャンデリアと7実ライト、50席と5小景の機能、18施工クラスター、3音響バス・
ホール残響・位置音源・音量切替、パーティー状態5秒間の描画性能も確認します。

```sh
npm i playwright-core   # 任意の場所で
node tools/verify.mjs 1280 800   # 横画面
node tools/verify.mjs 480 800    # 縦画面
```
