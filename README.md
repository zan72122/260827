# サンタの袋の中は、星空倉庫

4歳児向けのモバイルWebゲーム。北極の包装室に置かれた、どう見ても袋口より大きなプレゼントを、サンタの赤い袋へドラッグすると――包装紙とリボンが柔らかく圧縮されて「スポンッ」と吸い込まれ、カメラも袋口へ入り、赤い布繊維のトンネルを抜けて、袋の内側に広がる巨大な星空倉庫へ出る。

**「この袋は、外から見るより中がずっと大きい」** を、文字も矢印も使わず、最初の一操作で理解させることが中心のゲームです。

## 遊び方(すべて一本指)

1. 包装室で、リボンが袋の方へ揺れているプレゼントを袋口へドラッグ
2. 入口で一瞬止まり、包装が圧縮されて吸い込まれる。カメラも後を追う
3. 星空倉庫の中で、太い一筆で経路を描く — 星の粉が軌道に並び、プレゼントが少し遅れて追いかける
4. 三つの保管区画のどれかに届くと、他の贈り物の隣へ接地(または静かに浮遊)
5. 袋の絵のボタンで外へ戻ると、形の違う次のプレゼントが待っている
6. 三つ入れるとサンタが袋を持ち上げる — 外見上は、重みがわずかに増えただけ
7. 絵のメニューで「もう一つ入れる」「中を自由に飛ぶ」「袋口を出入りする」を選べる

失敗・制限時間・採点はありません。間違った保管区画も存在しません。

## プレゼント3種

| 種類 | 入口での入り方 | 内部移動時 | 置かれ方 |
|---|---|---|---|
| 木馬 | 頭から斜めに、中程度の圧縮 | 揺り木馬のように前後にロッキング | 接地して静かに揺れ続ける |
| 大きなぬいぐるみ | 大きく柔らかく圧縮され、ゆっくり沈む | 遅れてついてくるジェリー揺れ | 接地せず静かに浮遊 |
| 車輪のある玩具 | 縦向きになり長手方向からスライド | カーブでヨーイング+車輪の回転感 | 車輪で着地し少し転がって停止 |

## 技術

- **Vite + TypeScript + Three.js (WebGL2)**、外部アセットなし(全テクスチャをCanvasで手続き生成)
- 袋外と袋内は別シーン。**赤い布が画面を覆う瞬間**をシーン切替の隠し場所にしたmatch cut(黒画面・ローディング画面なし)。プレゼントは同一オブジェクトを両シーンで移動させるため、材質・包装色・リボン・回転が完全に一致
- 袋口の変形はCPU morph(開閉+プレゼント方向への布寄り)。包装紙・リボンの圧縮はauthoring済みの局所変形(entryAxis周りの radial squash + 軸方向 stretch + 紙の皺)
- 星は instanced billboard + 専用シェーダ(近景/中景/遠景の3層でサイズ・密度・明度を制御)。経路の星粉も同じ仕組みで、通過後は淡い残光として空間に残る(最大5経路)
- 経路は指の軌道を方向平滑化しながら等間隔でリサンプルした polyline を spline 追従。プレゼントは指より少し先(画面上方オフセット)を追う
- 袋内は最初のドラッグ中にフレーム分割で事前構築(遅延ロード)。テクスチャはキャッシュ共有。再出入りしてもGPUリソースが増えないことを `renderer.info` で実測
- 動的解像度(フレーム時間EMAでpixelRatioを0.55〜devicePixelRatioの間で調整)。`?q=low` で低品質開始

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # dist/ へビルド
npm run preview  # ビルドを 4173 番で配信
```

## 検証スクリプト(Playwright + Chromium)

実ブラウザでタッチ操作を行い、袋外→吸い込み→トンネル→経路描画→保管→帰還→二個目投入までを自動検証し、スクリーンショットを `shots/` に保存します。

```bash
npm run preview &
node scripts/drive.mjs iphone-portrait   # iphone-landscape / ipad-portrait / ipad-landscape
node scripts/drive-menu.mjs              # 3個保管→持ち上げ→絵メニュー→自由飛行→出入り
node scripts/capture-eval.mjs            # 最初の10秒と最初の一連操作の評価用フレーム
```
