# わたしのかばんは、飛行機のどこへ行く？

4歳児向けのモバイルWebゲーム。チェックインカウンターへ預けた一つの旅行かばんを、
**一回の連続スワイプ**で飛行機の貨物室まで追いかけます。

- 横画面：右方向へスワイプ（かばんは横方向に流れる側方視点）
- 縦画面：上方向／斜め上方向へスワイプ（奥へ上っていく追走視点に再設計）
- 指の現在位置が journeyProgress (0.0–1.0) を直接制御します。
  ムービーはありません。ゴム幕・検査装置・分岐器・ベルトローダーはすべて
  進捗の純関数として動くため、指を戻せば旅も滑らかに巻き戻ります。

## 遊び方

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # dist/ へビルド
npm run preview    # ビルドをプレビュー (port 4173)
npm run typecheck  # 型検査
npm run verify     # Playwright による自動検証（スクショ・スワイプ・回転・10回再演・メモリ）
```

スマートフォン/タブレットの実機では、`npm run dev -- --host` で同一LANから開けます。

## 旅程（journeyProgress）

| progress | 場面 |
|---|---|
| 0.00–0.10 | チェックインスケール／ベルト始動 |
| 0.10–0.22 | ゴム製ストリップカーテン（越境面 #1） |
| 0.22–0.40 | 地下ソートホール（下りベルト、センサー、保守通路） |
| 0.40–0.54 | インライン検査装置（遮蔽フラップ、タグ読取り） |
| 0.54–0.69 | 高速仕分け：パドル式分岐器が進路を切り替える運動的ピーク |
| 0.69–0.78 | ローラーシャッター → 地上のメイクアップ区画（手荷物台車・タグ車） |
| 0.78–0.90 | 建物出口（越境面 #2）→ 屋外エプロン、巨大な機体腹部の出現 |
| 0.90–0.98 | ベルトローダーの斜面を登る |
| 0.98–1.00 | 貨物室へ収まり、カーゴネットと他の荷物のそばで完了 |

## テストAPI

外部自動化用に `window.__BAGGAGE_GAME__` を公開しています。

```js
window.__BAGGAGE_GAME__.setProgress(0.5); // 任意の進捗へ移動
window.__BAGGAGE_GAME__.getProgress();
window.__BAGGAGE_GAME__.bagScreenPosition(); // かばんのスクリーン座標
window.__BAGGAGE_GAME__.rendererInfo();      // draw call / triangle 数など
```

## 実装メモ

- Vite + TypeScript + Three.js。アセットのネットワーク取得はゼロ
  （全テクスチャは canvas による手続き生成。決定的な乱数で毎回同一）。
  KTX2 は外部テクスチャ資産が存在しないため採用していません。
- かばんは単一の `Object3D` を全区間で使用。環境区間
  （CheckIn / Curtain / Underground / Screening / Sorter / MakeUp / Airside /
  Loader / CargoHold）は一つの連続ワールドに実配置され、進捗レンジで
  表示切替されるため、world transform・速度・回転は途切れません。
- タグは2関節（ループ＋カード）の手続きアニメーション（クロスシムなし）。
- 背景の他人のかばん・ローラー・エプロンの白線などは InstancedMesh。
- 動的影はかばん周辺だけを覆う追従シャドウカメラ1枚に限定。
- 音は全て WebAudio の手続き合成（ベルト駆動音、ローラー継ぎ目、ゴム幕、
  検査装置、分岐器のガチャン、地下の反響、屋外の風と遠いジェット、
  ローダーモーター、貨物室の床ローラー）。初回タッチで AudioContext を生成。
- 一指のみ・`touch-action: none`・Pointer Events・pointer capture・
  `pointercancel` 対応。斜め・蛇行・途中停止を許容し主要軸へ射影。
  速度・直線性・時間は採点しません。
