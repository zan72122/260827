# とおくへ いく おてがみ — 海外あて二連押し

4歳児向けの、小さな実3Dインタラクティブゲームです。
やることはひとつだけ。

> **とおくへいくおてがみに、2つのはんこをじゅんばんに押す。**

日本の郵便局員の押印業務（記念押印の「特印 → 和文日付印」の二連押し）から
着想を得ています。文字は一切使いません。

---

## 遊びかた

1. 光っているはんこを **1本の指でつかむ**
2. 封筒の **切手のあたり** へ運ぶ（光るリングが目印）
3. **指を離す**（またはその場で少し止める）と、はんこが下りて印影が出る
4. はんこは自分で持ち上がり、置き台へ戻る
5. 次のはんこが光る → 2つ目を押すと手紙が完成し、遠くへ飛んでいく
6. すぐに次の封筒が届く

判定はとても広く取ってあります（成功半径 1.05 ≒ 印面の3.5倍）。
近づくと磁石のように吸い寄せられ、多少ずれても気持ちよく決まります。
順番を守れるよう、いま押すべきはんこ以外はつかめません
（さわると小さく揺れて「こっちだよ」と伝えます）。

## 実3Dであることについて

擬似3Dは使っていません。すべて WebGL 空間の立体です。

| 要件 | 実装 |
| --- | --- |
| 実メッシュ・深度・遮蔽 | 全オブジェクトが `Mesh`。前後関係は深度テストのみで決まる |
| PerspectiveCamera | `fov 30〜42` を演出ごとに切り替え |
| 影 | `DirectionalLight` + PCFSoft シャドウマップ |
| PBR 材質 | `MeshStandardMaterial` に base color / roughness / metalness / normal を設定 |
| 環境光 | `RoomEnvironment` → PMREM の IBL |
| フォグ | `THREE.Fog`（カメラ空間の距離で減衰。奥行き情報と整合） |
| 回り込み | どのショットもゆっくり周回する。裏側・側面も連続した空間 |

**厚みと段差はすべてジオメトリで作っています。**

- 封筒 … `BoxGeometry(44×26分割)`。小口（紙の厚み）が実際に見える
- 切手 … `Shape` に半円の切り欠きを並べた **本物の目打ち**を `ExtrudeGeometry` で押し出し。
  封筒の上に浮いた段差として置かれ、印影はその段差を乗り越えて落ちる
- 印章 … 持ち手は `LatheGeometry` の挽き物形状、印面の縁は `TorusGeometry`、
  頭部・カラー・指かかりの溝もすべて実メッシュ
- 印面の彫刻模様だけは normal map（微細なレリーフのみ。立体の偽装には使っていない）

主役と接触対象に板画像（ビルボード）は一切使っていません。

## 印影の出しかた

`DecalGeometry` で、封筒本体と切手の**両方のメッシュに投影**しています。
つまり印影は平面に貼った板ではなく、紙の面と切手の段差に沿った実ジオメトリです。

- 接触の瞬間に、**残る形のくぼみを先に作ってから**デカールを生成する
  （押し込みが戻っても印影が浮かない）
- 出現はシェーダのマスクリビール。中心からノイズで揺らぎながらインクが移る
- 印章が持ち上がるのに同期して現れる（隠れている間に完成してしまわない）
- テクスチャは毎回生成し直すので、かすれ・濃淡・押し圧の偏りが 1 回ごとに違う

紙のたわみは頂点変形です。押し跡は `envelope.userData.dents` に蓄積するので、
2つ目を押しても1つ目のくぼみは消えません。押した縁がわずかに盛り上がります。

## カメラ（自由操作なし）

因果の途中でカットしません。すべて連続した補間で、フェーズ間をつなぎます。

| ショット | いつ | 何を見せるか |
| --- | --- | --- |
| Establish | 開始時 | カウンター全体・封筒・2つのはんこの距離関係 |
| Alignment | つかんだ瞬間 | いま使うはんこと、切手まわりの押す場所 |
| Action | 下ろし始め | 印面が紙へ近づくところ |
| Material macro | 接触の直前 | 印面が紙に触れ、インクが移る瞬間 |
| Reveal | 持ち上げた後 | 2つの印影が並んだ完成形 |
| Return | 完成後 | 引いて、次の封筒が届く |

**自動フレーミング**: 各ショットは「画面に必ず入れたい点」を宣言し、
`fitShot()` がそれらが収まるまでカメラを引きます。周回の両端でも判定するので、
iPhone の縦持ちでも iPad の横持ちでも主役が切れません。

## 4歳児のための設計

- **文字ゼロ**。誘導は 3D の矢印・脈動するリング・主役自身の呼吸だけ
- 最初は 1個目にだけ誘導。5秒さわらなければ「押す場所」もそっと光る
- 2個目は、1個目を押し終えた瞬間に自然と目立つ（体験で意味が分かる）
- **指で隠れない**: ドラッグ中のはんこは指より奥（画面では上）へ 0.24 ずらし、
  さらに紙面から 0.62 浮かせる。印影が出る位置は必ず指より上に見える
- 指を離せない子のために、目標の上で少し止めるだけでも押せる
- 失敗という状態がない。外れたはんこはそっと置き台へ戻るだけ
- メニュー・サブゲーム・スコアなし。看板動作だけ

## モバイル性能

- 描画コール **約 80**（影パス込み）、三角形 **約 1.8万**（実測）
- 影を落とすライトは 1灯のみ。1024 のシャドウマップ
- ポストプロセスなし。`devicePixelRatio` は 2 で頭打ち
- フレーム時間が 26ms を超え続けたら、自動で解像度と影を落とす
  （**平面化はしない**。落とすのは解像度と影の精度だけ）
- テクスチャはすべて手続き生成（外部アセットのダウンロードなし）

## ファイル

```
index.html          … 画面と import map（three は vendor/ から）
src/main.js         … ゲーム進行・カメラ演出・入力・完成演出
src/objects.js      … 封筒 / 切手 / 印章 / カウンターの実メッシュ生成
src/textures.js     … 紙の繊維・木目・印影など手続き的テクスチャ
vendor/             … three.js r169（MIT）
```

`src/main.js` の末尾には自動テスト用の小さなフック
（`__probe` / `__state` / `__drop`）があります。ゲーム進行には影響しません。
