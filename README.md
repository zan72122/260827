# 水面上／水中の因果劇場

ワカサギ用ドーム船の釣り座を、一本の糸が水面を貫く一つの3D空間として描いたモバイルWebゲームです。
文字も音声解説も使わず、「水の下の魚が、どうして水の上の竿を動かすのか」を、
見えない原因 → 見える小さな信号 → 自分の操作による確認 の順に体験させます。

## 遊び方

- 上下に短くスワイプすると仕掛けが動きます（誘い）。
- 指を離すと止まります。止めている間だけ魚が餌へ寄ってきます。
- 穂先が短くピクッと動いたら、短く上へクイッと弾きます（合わせ）。
- 長く下へドラッグすると仕掛けが深くなり、上へドラッグすると浅くなります。

## 三幕

| | 水中の見え方 | カメラ | 子どもが読むもの |
|---|---|---|---|
| 第一幕 | 釣り座まわりだけを断面にした局所カットアウェイ | 水面をまたぐ側面3/4 | 魚→糸→水面→穂先の連続した因果 |
| 第二幕 | 餌の近くだけが澄んだ小さなポケット | 穂先が主役 | 穂先の信号から不可視の原因を推測 |
| 第三幕 | 通常の濃紺（水中は見えない） | 水上のみ、穂先の背後を整理 | ゆっくりユラユラ＝船／短いピクッ＝魚 |

正しく合わせた直後だけ、第二幕ではカメラが糸に沿って水中へ降り、推測と実際の原因が
一致していたことを確かめてから穂先へ戻ります。

## 構成

- `src/world.ts` — 唯一の共有world model。lurePosition / lureMotion / lineTension /
  fishIntent / fishContact / boatSway / rodTipDeflection / cutawayVisibility / reelState を持ち、
  水上表示・水中表示・音のすべてがここから描かれます。1/120秒の固定サブステップで積分します。
- `src/gfx/shaderlib.ts` — 全マテリアルが共有するuniformとGLSL。局所カットアウェイの
  マスク（甲板の断面／水面のくさび／餌まわりの澄んだポケット）と、水中の減衰・散乱を定義します。
  湖全体を透明にはしません。
- `src/gfx/boat.ts` — 甲板、床厚のある釣り口、縁材、根太、船体、窓の開口、吊下ランプ。
  ローカル+Xがカメラ側になる向きで作られているので、断面は local x = 0 の面です。
- `src/gfx/rod.ts` — テーパーした穂先。曲げは片持ち梁の形状関数で、
  速い減衰振動（アタリ）と遅い振動（船の揺れ）を重ねます。
- `src/gfx/rig.ts` / `ribbon.ts` — 糸、三本の枝糸、餌、オモリ。糸は視線に正対する
  細いリボンで、最小1px程度を保ちつつ発光はしません。
- `src/gfx/fish.ts` — 個別制御の4匹と、遠くの群れのインスタンシング。
- `src/gfx/water.ts` — 水面（フレネル、船底の映り込み、釣り口から差す光、糸の侵入点の波紋）、
  水の体積、湖底、漂う微粒子。

## 開発

```
npm install
npm run dev        # 開発サーバ
npm run typecheck  # 型検査
npm run build      # 型検査 + 本番ビルド
npm run preview    # 本番ビルドの確認
```

WebGL 2 が基準です。WebGPUが使える端末では魚群数と粒子数を上乗せします。
DPRと影は実測フレーム時間に応じて自動的に落とします。
