# ぺったん ふうけいいん

すきな きれいな はんこを えらんで、おてがみに ぺったんする。
4さい向けの、モバイル Web ゲームです。

郵便局の窓口にある特別日付印（風景印・記念印）の押印をヒントにした、
**選ぶ → ぺったん → きれい！ → 集まる** の短いくり返しだけでできています。
文字は一切出てきません。指1本で最後まで遊べます。

## あそびかた

1. うしろの台に、4本のはんこが立てかけてあります。印面の絵がそれぞれ違います。
2. すきなはんこを **タップ** するか、そのまま **ドラッグ** します。
3. はがきの上の、ちかちか光る丸へ運んで、指をはなすと **ぺったん**。
4. 印影がにじんで出てきて、はんこを持ち上げると絵が見えます。
5. 押しおわったはがきは、うしろの棚へ立てかけられ、つぎのまっさらなはがきが出てきます。
6. 机の左右にある **インクパッド** の上をはんこで通ると、インクの色が変わります。
   （4つの意匠 × 4つの色 = 16通りの印影が集まります）

インクが薄くなってくると印影がかすれ、色の合うパッドがそっと呼吸して知らせます。

## 技術メモ

- **完全な WebGL 実3D**です。PerspectiveCamera、実メッシュ、深度テスト、
  シャドウマップ、PBR（MeshStandardMaterial / MeshPhysicalMaterial）、
  PMREM で焼いた環境光を使っています。板ポリゴンでの疑似3D、
  z-index による前後の解決は使っていません。
- はんこの持ち手は LatheGeometry のろくろ挽き、ゴム印面は円柱＋段差、
  切手は半円の切り欠き（ミシン目）を実際に刻んだ ExtrudeGeometry、
  はがき・台紙・トレー・インク缶もすべて厚みを持った立体です。
  近づいても側面・裏側・段差が成立します。
- **テクスチャは全て手続き生成**（Canvas 2D）。外部アセットはひとつもありません。
  木の年輪と導管、紙の繊維と漉きムラ、ゴムの微細な凹凸、湿ったインクの布目、
  風景印の線画意匠、切手の図案はすべてコードで描いています。
- 印影は**軽量なデカール**（1枚の板＋アルファ）です。押すたびに、かすれ・濃淡・
  にじみ・手押しのゆらぎを乱数で作り直すので、同じ印影は二度と出ません。
- 効果音は WebAudio の合成音のみ。音声ファイルはありません。
- 背景（壁・棚・小包）はローポリの簡略表現に留め、ポリゴンとテクスチャは
  主役（はんこ・インク・紙）に寄せています。
  描画は 20k 三角形 / 70 ドローコール前後。
- iPhone / iPad 向けに、devicePixelRatio は 2 で頭打ち、
  fps が落ちたら解像度を静かに下げる適応処理を入れています。
- three.js r160 を `vendor/` に同梱しているので、CDN なし・オフラインでも動きます。

## うごかす

静的ファイルを配信するだけです。

```sh
npx http-server -p 8080 -c-1 .
# → http://localhost:8080/
```

1ファイルにまとめたい場合（配布用・オフライン用）：

```sh
node build.js          # dist/index.html が出ます
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面と、最小限の DOM（読み込み表示と音のオンオフだけ） |
| `src/main.js` | 起動・入力・ゲームの流れ（選ぶ→押す→現れる→集まる） |
| `src/world.js` | 机、スタンプ立て、インクパッド、集めたカードの棚、光、環境マップ |
| `src/stamp.js` | はんこ本体（持ち手・色帯・ゴム印面） |
| `src/card.js` | はがき、切手、印影デカール |
| `src/impression.js` | 印影づくり（かすれ・濃淡・にじみ）と印面テクスチャ |
| `src/seals.js` | 風景印風のオリジナル意匠と、切手の図案 |
| `src/textures.js` | 木・紙・ゴム・布などの手続き的テクスチャ |
| `src/camera.js` | 「見せたいものを画面に収める」宣言的カメラ |
| `src/fx.js` | きらきら、インクの波紋、着地点の光 |
| `src/audio.js` | 合成効果音 |
| `src/anim.js` | 小さなアニメーション基盤 |

意匠はすべてオリジナルです。実在する郵便局の公式意匠の複製ではありません。
