# エサ雪 ― 小魚の群れを呼ぼう

4歳児向けの、写実寄りモバイルWebゲーム。舞台は朝の海釣り施設。

遊びの中心は「たくさん釣ること」ではなく、
**餌の付いていない仕掛けには見向きもしなかった小魚が、
アミの粒が雪のように落ちはじめると向きを変えて集まってくる** ―
その因果を、自分の操作から見つけることです。

## 因果の鎖

1. 餌なしの試験仕掛けを海へ下ろす → 群れは近くを通るが、ほとんど向きを変えない
2. 巻き上げると、近景に餌付け容器（アミの入ったバケツ）がある
3. 幅広いガイドを前後に動かすと、仕掛けが容器の中を横切り、アミが針に付く
4. 下ろすと、餌粒が針から少しずつ外れて沈み、潮流で横へ流れる
5. 粒の密度が高い方向へ、**まず一匹**が向きを変える
6. 近くの数匹が続き、群れ全体の軌跡が曲がり、仕掛けの周りに集まる
7. 小さく一度しゃくって指を離す → 穂先がピクッとする → 短い上スワイプで合わせる
8. 電動リールを長押しして巻き上げ、自動魚外し器を通って観察水槽へ

文章による指示・矢印・数値UIは使っていません。手掛かりはすべて物の側にあります
（開いたガイド溝、係員が糸を保持する手、容器を動かすと崩れる湿ったアミ）。
失敗音・ゲームオーバー・赤い×印はありません。合わせを外しても魚は戻ってきます。

## 一変数ずつの実験

二回目以降は一つだけ条件が変わります。数値は出さず、見た目だけで差が分かります。

| 変数 | 操作 | 見える差 |
| --- | --- | --- |
| 餌量 | ガイドを1往復 / 2往復 | 餌雪の密度（粒数がおよそ2倍）と、群れが向きを変えるまでの時間 |
| 深さ | スワイプをどこで離すか | 群れより浅い＝到達が遅く、下から近づく／同じ深さ＝早く、仕掛けに密集 |
| 流れ | 第4試行以降に潮が変わる | 粒の軌跡、ロープと海藻の傾き、群れが溜まる位置が風下側にずれる |

どの条件でも最終的に魚は寄ります。違うのは群れの形、到着経路、待ち時間です。

## 操作

- 大きなガイドを左右にドラッグ（画面のどこでも効く。斜めでも餌付けとして認識）
- 下スワイプで仕掛けを降ろす／指を離すと止まる
- 小さく上下（しゃくり）→ 指を離す
- 短い上フリックで合わせ
- 電動リールのダイヤルを長押し（見た目より広い判定。画面外なら任意長押しで代用）

細い仕掛けを直接つまませることはありません。ジェスチャの感度は画面サイズ基準なので、
縦横どちらでも同じ大きさの指の動きで同じだけ動きます。

## 実装

Vite + TypeScript + Three.js（WebGL 2）。外部アセットはゼロで、
テクスチャ（コンクリートの骨材、亜鉛めっきのスパングル、湿ったアミ、魚の肌…）は
すべて実行時に Canvas で生成しています。

- `src/sim/BaitSnow.ts` … 餌粒。プール済み InstancedMesh、個体ごとの沈降速度・粒径、
  単純な流れ場＋弱い乱流。描画されない微細な粉は密度場に円錐状の尾として書き込む。
- `src/sim/DensityField.ts` … 18×20×14 の低解像度スカラー場。魚が読むのはこれだけ。
- `src/sim/School.ts` … 分離・整列・結合に、密度勾配へのステアリングを足した群れ。
  最初の一匹が単独で向きを変えてから 1.3 秒は勧誘が始まらず、その後 0.4 秒ごとに
  近傍1匹ずつ伝播する。瞬間移動はしない。遠景は InstancedMesh、3匹だけ個別mesh。
- `src/scene/Water.ts` … 水面シェーダと、全マテリアルに注入する水中減衰
  （赤から先に消える指数減衰）。cutaway は水面の局所的な切り抜きで、
  空気と水中を同一フレームに写す。
- `src/game/Game.ts` … 状態機械と11ショットのカメラ鎖。縦横で別の画角を持ち、
  回転しても粒・仕掛け深度・群れの状態は保持される。

品質段階は `navigator.gpu` の有無とメモリ/コア数で選択（粒 55/95/150、魚 44/66/96、
影の有無）。DPR上限つき適応解像度あり。釣り座を先に描画し、遠景の港湾設備・水中の
濁り・群れの残りは初回フレーム後に読み込みます。

音はすべて WebAudio による合成音（アミと樹脂の擦れ、糸、着水、群れの翻り、リールのモーター）。

## 開発

```
npm install
npm run dev        # 開発サーバ
npm run typecheck  # 型検査
npm run build      # 型検査 + 本番ビルド
```

### 検証用ハーネス

`tools/` にヘッドレス実機検証用のスクリプトがあります（Playwright が必要。
`npm i -D playwright` またはグローバル版を `node_modules/playwright` に symlink）。

```
npx vite build && npx http-server dist -p 4173 --silent &
node tools/run-loop.mjs      # 餌なし→餌付け→投入→群れ→合わせ→巻き上げ→再試行を2周
node tools/conditions.mjs    # 餌なし/1回/2回/浅い/同深度/横流れ の比較スクリーンショット
VIEW=844x390 TAG=l node tools/land2.mjs   # 横画面 + 途中回転
```

スクリーンショットは `shots/` に出力されます。
