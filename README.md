# うみのケーブルせん (Sea Cable Kids)

4歳児向けの海底ケーブル敷設ゲーム。iPhone / iPad のモバイルブラウザで動く、
静的配信可能な TypeScript + Three.js (WebGL 2) 製 Web アプリです。

「大きなお船から長い線を海の底へ置いて、島と島をつないだ」――
子どもが一筆で描いたルートが、そのまま

- 海面を進むケーブル敷設船の航路
- 船尾から繰り出されるケーブルの形（水中の懸垂カーブ）
- 海底へ残る実際の敷設経路

になります。ケーブルは黒い外装の物理的な実体として描かれ、
通信の開始は陸上局の状態灯と結果画面の海図表示だけで伝えます
（海中のケーブル自体は光りません）。

## 遊びの流れ

1. **オープニング** – ケーブルタンク → テンショナー → 船尾シーブ → 海、と
   ケーブルの通り道をデッキツアーで一度見せる（タップでスキップ可）
2. **航路計画** – 透明度の高い海越しに海底地形（砂地・岩場・海草域・海底谷）を
   読みながら、始点の接続点から終点まで一筆でルートを描く
3. **敷設** – 船が描いた曲線を航行し、タンクのコイルが減り、ローラーが回り、
   船尾から海へ、水中の懸垂カーブ、着底、砂泥底では埋設機が浅い溝を掘って
   埋め戻す――カメラはケーブルに沿って海面から海底まで連続移動
4. **接続** – 陸上局のランプが緑になり、島の暮らしに灯りがともる
5. **結果の海図** – 自分のルートと別の成立ルートを見比べ、海図上だけを
   信号パルスが走る。リプレイごとに地形が少し変わる

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型検査 + 本番ビルド (dist/ を静的配信)
npm run preview    # ビルドのプレビュー
```

自動プレイテスト（Playwright + ローカル Chromium）:

```bash
npm run build && npx vite preview --port 4173 &
node scripts/playtest.mjs
```

直線・左右の大迂回・S字・途中離し・手ぶれ・岩場沿いの 7 シナリオを
実ポインタ操作で描き、ルート形状の保存、曲率制限、ケーブルの連続性、
回転後の状態保持、フレーム性能などを検証します。

## 実装メモ

- ルートは Pointer Events を正規化座標で受け、海面平面へレイキャストした
  世界座標で保存（縦横回転後も海底座標として不変）
- ストローク処理: 迂回形状の保存 / 指ぶれ除去 / 最小曲げ半径への曲率丸め /
  始終点スナップ。最短経路への自動置換はしない
- 海底ケーブルはルート曲率に応じた適応間隔のリング列から生成し、
  drawRange で敷設進行を表示。船尾〜着底点はエルミート近似の懸垂カーブを
  毎フレーム少数リングで再構築（柔体シミュレーションなし）
- 海面は低周波の頂点波 + 解析法線 + フレネル + 深度色（流体シミュなし）。
  計画中は透明度を上げ海底を読めるようにする
- 水中は深度でフォグ色・密度・光量を変え、浮遊粒子・コースティクスで
  表層 / 中層 / 海底を描き分け
- 端末性能に応じた品質段階と描画バッファ上限 (WebGL 2 が最低成立ライン)
- 広告・ログイン・外部通信・課金なし
