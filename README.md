# くるくる、お花のバースデー

回転台でケーキをととのえ、フラワーネイルを回してクリームの花を絞り、
その花をケーキに移して、誕生日の席へ運び、ろうそくを消して、
花のついた一切れを相手にわたす。iPhone / iPad の Safari で、
指いっぱい 1 本で遊べる WebGL 3D の小品です。

文字は出ません。時間制限も、点数も、失敗もありません。

---

## 起動方法

```bash
npm install
npm run dev        # 開発サーバ（Vite）。表示された URL を開く
```

本番ビルドと確認：

```bash
npm run typecheck  # 型検査のみ
npm run build      # 型検査 + 本番ビルド（dist/）
npm run preview    # dist を 4173 番で配信
```

同一 LAN の実機で試す場合は `npm run dev -- --host` で表示される
ネットワーク URL を端末で開いてください。

必要なもの：Node.js 20 以上、**WebGL 2** に対応したブラウザ。
実行時に外部へ通信しません。API キー、ログイン、個人情報の入力はありません。

## 遊びかた（すべて絵で示されます）

1. **席をえらぶ** — 最初のタッチで音が有効になり、同時に贈る相手の席札
   （花の絵 / 葉の絵）を選びます。
2. **回してととのえる** — 回転台のあたりを指でなぞるとケーキが回り、
   ヘラが当たっている部分だけ塗りむらが消えます。取れたクリームはヘラに残ります。
   1 周する必要はありません。短い弧でも先へ進めます。
3. **花をしぼる** — カメラが脇の小さな金属台（フラワーネイル）へ寄ります。
   指で弧を描くと台が回り、口金からクリームの帯が出て、
   数枚重なったところで花として読めるようになります。
   円をきれいに描く必要はありません。**長押しでも進みます。**
   3 枚たまったら、そのまま小さく仕上げるか、外側の花びらを足すかを絵で選べます。
   食用色は 3 色、いつでも切り替えられます。
4. **ケーキへ移す** — リフターが紙の上から花をすくい上げます。
   ケーキの上をタップすると、その位置に置かれます。紙と金属は作業台に残ります。
5. **席へ運ぶ／ろうそくを消す** — 選んだ席へケーキが運ばれ、
   花から離れた場所のろうそくに火がつきます。画面を指ではらうと消えます。
   消したくなければ、矢印の絵で先へ進めます。
6. **切ってわたす** — ろうそくを外し、花を避けた 2 本の切り目で一切れを取り分け、
   同じ花が載った同じ一切れが、選んだ席のお皿へ移ります。
7. **そのあと** — 眺める時間のあと、「もう一つ花を作る」「別の席へ贈る」を
   絵で選べます。花作りは **1 タップ**で再開します。

右上のスピーカーの絵で音を切れます。音を切っても進行に支障はありません。

## 実装範囲

作ったもの：

- 花びらの**実ジオメトリ**による形成。口金の移動に沿って伸びる、
  根元が厚く自由縁が薄い帯状メッシュ。前後の面と重なりによる遮蔽を持ちます
  （`src/flower/PetalMesh.ts`, `src/flower/petalPath.ts`）。
- 一指の弧を、ネイルの回転・口金の軌道・絞り量へ同時に変換する入力
  （`src/stages/FlowerStage.ts`）。長押しの補助あり。
- 花の生成履歴（花びらごとの角度・半径・帯幅・厚み・反り・色）を保持する記録と、
  それだけから同じ花を再構築する仕組み（`src/core/FlowerRecord.ts`）。
  紙 → リフター → ケーキ → 皿と座標系だけが変わり、形は作り直されません。
- 回転台とヘラによる塗りむらの除去（接触部分のみ）。
- ケーキの実体：切ると 2 つの扇形へ組み直され、断面にスポンジとフィリングの層が出ます
  （`src/build/Cake.ts`）。花の位置を避けた 2 本の切り目を計算します。
- 花びら口金の実形状（涙形のスロット、板厚 0.32 mm、開口の縁）
  （`src/build/PipingTip.ts`）。
- 手：指の曲げを「持っている物の表面に指先が来る」よう数値的に解いているので、
  道具が宙に浮くことがありません（`src/build/Hands.ts`）。
- 昼の窓光と暖色の食卓照明の 2 系統、手続き生成の環境マップ。
- Web Audio による合成音（外部音源なし）。
- 縦横のショットを別に持つカメラ演出。操作中は固定、工程間のみ移動。

作っていないもの（指示により意図的に）：

- 調理学校・経営・材料購入・計量の工程
- 自由な人物移動、顔や全身のモデル
- 時間制限、採点、失敗、広告、課金、ログイン、個人情報
- WebGPU との二重実装、汎用製菓エンジン
- 全微細粒子の物理、完全な手の物理、重い被写界深度

## 開発用の確認手段

ゲーム中に次のキーが使えます（子ども向けの操作には出てきません）。

| キー | はたらき |
| --- | --- |
| `V` | 主役の立体を確かめる別視点を順に切り替え（花の真横・背面・真上・反対側、ケーキ、部屋全景）。もう一度押すと通常のカメラへ戻ります |
| `L` | 照明を切り替え（標準 → 曇天 → 夜の食卓）。材質と形が破綻しないかを見るため |
| `I` | ステージ、fps、内部解像度、ジオメトリ／テクスチャ／プログラム数、描画コール数を表示 |

`I` の表示は再プレイ時に資源が増え続けていないかを見るのに使えます。

## 構成

```
src/
  core/      units, CakeState, FlowerRecord, Storage   ゲームの状態（描画から独立）
  flower/    petalPath, PetalMesh, FlowerBuilder       花びらの形成
  build/     geometry, PipingTip, Hands, Cake, tools, Room   形の生成
  render/    textures, materials, Environment          見え方
  camera/    CameraDirector                            画角と工程間の移動
  input/     PointerInput                              一指の扱い
  audio/     AudioKit                                  合成音
  ui/        Overlay, icons                            絵だけの操作
  stages/    Welcome, TurntableOperation, FlowerStage,
             FlowerTransfer, ServeStage, ServingCut, AfterStage
  app/       App, World, StageContext                  配線
tools/
  capture.mjs   画面と資源使用量を記録する検証用ハーネス
```

状態（`CakeState` と `FlowerRecord`）は描画から分離してあり、
花は生成パラメータだけで完全に再構築できます。
`localStorage` への保存は失敗しても無視され、ゲームは止まりません。
