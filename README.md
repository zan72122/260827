# ガラスこうぼう — 板ガラス切断ゲーム

4歳児が一指で成人職人の手を操作し、板ガラスへ一筆のスコア（切り筋）を入れ、
running pliers で力を加えて「パキッ」と二片へ割る、写実系モバイルWebゲームです。
iPhone / iPad の縦横両画面に対応します。

## 遊びかた（文字なしで遊べます）

1. 職人が吸着具で板ガラスを切断台のフェルトへ置く
2. 光る点から反対の縁へ、一筆でスワイプ（曲げた分だけスコアが曲がる）
3. 職人が running pliers をスコアの端へあてる → 光る所をタップ
4. 亀裂が一筆の順序でスコアを走り、板が軌跡どおりの二片へ分かれる
5. 職人が片方を窓の光へ掲げ、切断形状の色光が床へ落ちる
6. 色ガラスを選んでもう一回

## 現実工程への根拠

一次資料（板ガラス・工具メーカー、安全取扱資料）に基づき、次を描いています。

- パッド（フェルト）付き切断台と縁保護
- 数mm厚フロート板ガラス
- 油送り式・小径超硬切断輪のガラスカッター（連続一回スコア、往復なし)
- running pliers による制御された曲げ割断（火花・レーザー・溶融・粉砕なし）
- 耐切創手袋・長袖の職人、ベンチ上の保護眼鏡・予備手袋
- 大板搬送用の吸着具、ガラスラック

子ども本人は作業者として描かれず、指は職人の手と工具へ対応します。

## 技術構成

- Three.js (WebGL 2) 単体。追加のポリゴンライブラリなし
  （矩形×単純曲線の分割は自前実装、三角形分割は Three 同梱の earcut）
- 板ガラス: 2D輪郭を板厚押し出しした閉メッシュ
  （表・裏・工場縁・切断面をマテリアルグループで分離、transmission による屈折表現）
- スコア: 入力と同時に敷かれるリボン（カッター輪より先に現れない）
- 分割: スコア確定後に矩形輪郭を二つの単純多角形へ分割 → 各々を押し出し。
  割断完了の瞬間に単板メッシュと置換するため、事前に二片へ見えない
- 色光: 切片シルエットの blur テクスチャを床へ投影する擬似投影
- 音: WebAudio 合成のみ（スコアのヒス、亀裂のティック、割断のスナップ）
- 高DPI管理: DPR上限2 + 総ピクセル予算でスケール

## 開発

```bash
npm install
npm run dev       # 開発サーバ
npm run build     # production build -> dist/
npm run shots     # 実プレイ検証 + スクリーンショット -> shots/
```

`npm run shots` は8種の軌跡（直線・右膨らみ・左膨らみ・斜め・波形・短速・長遅・
縁内側開始）を実際に切断し、ジオメトリ検証（開放辺・法線・面積保存）と
390×844 / 844×390 / 820×1180 / 1180×820 の5段階スクリーンショットを保存します。
