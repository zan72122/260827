# しょうぼう みずまき くんれん

4歳児向けの消防放水ゲーム。iPhone / iPad のブラウザ(縦・横どちらでも)で遊べます。

舞台は**無人の消防訓練場**。完全防護装備の大人の消防士がホースを支え、プレイヤーの指がノズルの向きを決めます。燃えるのは金属訓練パン・耐火レンガ囲いの設備・木製燃焼クリブだけで、人・動物・建物火災は登場しません。

## 遊び方

1. 起動して水滴ボタンをタップ(文字なしで開始できます)
2. 数秒の準備シーン: ホース展張 → カップリング接続 → バルブ開放 → ホース加圧 → ノズル構え(タップでスキップ)
3. 画面に指を置いている間だけ放水。指の少し**上**に着水点が出るので、指で水や炎が隠れません
4. 指を動かした軌跡どおりに水が移動します
   - 留まればそこが深く濡れ、火が早く弱まる
   - 左右に振れば散水帯、円を描けば円形の濡れ跡
   - 着水していない離れた火は消えません
5. 全部消えると静かな数秒のあと、もう一回ボタン(↻)で同じ配置をやり直せます

失敗・制限時間・スコアはありません。

## 実行方法

```bash
npm install
npm run dev        # 開発サーバ (LAN公開: 実機のSafari/Chromeから http://<PCのIP>:5173)
npm run build      # 型検査 + 本番ビルド (dist/)
npm run preview    # ビルド結果の配信 (port 4173)
npm run playtest   # ビルド後、ヘッドレスChromiumで自動試遊 (要 build 済み)
```

- iPhone/iPad実機では `npm run dev -- --host` でLANに公開し、同一Wi-FiのSafariで開くのが手軽です
- 音はWebAudioで全て手続き生成(素材ファイルなし)。最初のタップで有効になります

## 技術構成

TypeScript + Three.js + Vite(WebGL 2)。役割分担でモバイル負荷を管理しています。

| 役割 | 実装 |
|---|---|
| 水の中心流 | 放物線に沿って毎フレーム変形する固定トポロジのチューブメッシュ + 揺らぎ/縁泡/末端分裂シェーダ |
| 外縁飛沫・着水飛沫・蒸気・煙・滴り | 単一プールのパーティクル(1ドローコール、画面外/寿命で回収) |
| 濡れ跡 | ワールドXZのレンダーターゲットに着水スプラットを蓄積。対応マテリアルはアルベド暗化+粗さ低下(艶) |
| 炎 | 火点ごとにビルボード群1メッシュ+手続きノイズシェーダ。強度で高さ・色温度・光量・煙量・燃焼音が低下 |
| ホース | 少数コントロールポイントのスプライン+固定トポロジチューブ(全長柔体なし) |
| 入力 | Pointer Events + pointer capture。指の軌跡を平滑化した着水点が連続移動し、移動区間を細分して濡れ/消火を毎フレーム適用(最後の点だけ使う実装ではない) |
| 描画制御 | ピクセル比上限2 + 低fps時の自動減、影1枚、スワイプ中カメラ固定 |

`window.__ffgame` に自動テスト用のデバッグAPI(火勢・濡れサンプル・着水軌跡・カメラ姿勢など)を公開しています。

## 自動試遊 (playtest/run.mjs)

中央静止 / 左右往復(両方向) / 円 / 速い・遅い横掃き / 短タッチ / 指がキャンバス外へ出る操作 / 画面回転 / 全消火→再挑戦 を実際のポインタ操作で実行し、24項目を検証します(着水点の連続移動、掃き速度による濡れの差、離れた火が消えないこと、回転後の状態保持、指と着水点の分離など)。スクリーンショットは `playtest/shots/` に出力されます。
