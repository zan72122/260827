# トナカイ、みんなつながった！

4歳児向けの iPhone / iPad 用モバイル Web ゲーム。
雪の厩舎前で、離れて立つトナカイとそりを革の牽引線でつなぎ、
三頭の編成が一つになって動き出すまでを指で組み立てる。

## 遊びの流れ

1. **謎**: トナカイが歩いても、そりは動かない。地面にはトナカイ側とそり側に
   分かれた革線が垂れている（矢印や文字の誘導はなし。トナカイの視線と
   線の揺れだけが手がかり）。
2. **理解**: 線の端をそり側の金具へドラッグすると「カチン」。トナカイが
   一歩進み、革が張り、そりが雪を押して動く——すべて同じショットの中で起きる。
3. **編成**: 残り二頭を自由な順番で準備する。
   - 大きなブラシで毛並みに沿って雪を払う
   - 首輪 / 胸当てを運んで載せる（厚いパッドが体に沿って落ち着く）
   - 革端をバックルへ「カチン」
   - 真鍮の鈴を好きな吊り輪へ（位置で揺れと音が変わる）
   - 牽引線を三つのフックのどれかへ（どのフックを選ぶかで編成が決まる）
4. **出発**: 三頭がつながるとサンタが手綱を軽く引き、耳→頭→前脚→鈴→
   張り→ランナーの順に一頭ずつ連鎖して動き出す。
5. **走行**: 上へスワイプし続けると 歩き→速歩→雪が流れ→そりが軽くなり→
   全頭がふわりと浮く。指を止めると降りて止まり、また自由に組み直せる。

誤った場所に装具を置いても、トナカイが首をかしげて装具が戻るだけ。
文字・点数・制限時間・失敗表示はない。

## 技術

- TypeScript + Three.js (WebGL2)。外部アセットなし（形状・テクスチャ・音を
  すべて実行時に生成）
- トナカイ: 断面ロフトによるプロシージャル形状 + グループ階層の共有リグ。
  体格・毛色・枝角・顔の模様は個体パラメータ
- 牽引線: 少数制御点の簡易 Verlet + 張り形状への補間（重いロープ物理なし）
- 鈴: InstancedMesh + 振り子シミュレーション + WebAudio 合成音
- 雪: 接地時の局所パーティクル、そり跡/蹄跡はリングバッファのリボン/インスタンス
- 動的品質調整（フレーム時間を実測して解像度を段階変更、DPR 上限 2.0）
- リプレイしてもメッシュ・ジオメトリ・オーディオノードは増えない

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # dist/ へビルド
npm run preview    # ビルドをプレビュー (port 4173)
```

### 検証ツール

```bash
# 全工程（接続→装着→三頭編成→離陸→自由モード→リプレイ）を
# 実際のポインタ操作で通しプレイし、リークも点検する
node tools/drive.mjs 390 844 /tmp/drive_portrait    # iPhone 縦
node tools/drive.mjs 844 390 /tmp/drive_landscape   # iPhone 横
node tools/drive.mjs 1024 768 /tmp/drive_ipad       # iPad 横

# スクリーンショット1枚（?cam=side|front|tq|back でトナカイ接写）
node tools/shot.mjs 390 844 out.png 6000
```
