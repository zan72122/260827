# こおりのふね — 一筆描きの砕氷船ゲーム

iPhone / iPad のモバイル Safari で遊べる、4歳児向けの写実寄り 3D 砕氷船ゲームです。
TypeScript + Three.js だけで動く静的 Web ゲームで、バックエンド・アカウント・広告・課金・分析 SDK はありません。

## 遊びかた

1. 導入映像: 氷に閉じ込められた補給船と、遠くの小さな港が映ります(タップでスキップ)。
2. 高い斜め俯瞰に固定されたら、**砕氷船から港の方向へ、指一本で一筆の線を描きます**。
   細い白い航路線(海図の鉛筆線)がプレビューされます。
3. 指を離すと、砕氷船がその線を船体の慣性と最小旋回半径を保ちながら追いかけ、
   船首で氷に乗り上げ → 亀裂 → 板氷の押し分け → 船尾に暗い水路、の順で氷を割ります。
4. 砕氷船が通り終えると、補給船が**あなたの作った水路を通って**港に着き、
   小さなクレーンが荷物を降ろします。
5. 終了後は 2 つの丸ボタン: ↺ 同じ氷原でもう一回 / ❄ 新しい氷配置。

ゲームオーバー・沈没・燃料・時間制限・星評価はありません。
どんな穏やかな線でも、その形の航路として成立します。

## 一筆操作の契約

- 右に曲げた線は右に曲がる航路、左は左、S字はS字、長い線は長い水路になります。通過順序は入れ替えません。
- 速い入力はやや力強い航行、遅い入力は重く慎重な航行になります(±15%)。
- 指の震え(数px)は等距離リサンプリング+軽い平滑化で除去しますが、大きな曲率は残します。
- 実艦が通れない鋭角だけを最小旋回半径(55 m)の pure pursuit で丸めます。
- 島やアザラシの氷盤に近づくと、少し早めに旋回を広げて回避します(左右の選択は反転しません)。
- 描いた線が短い場合も、砕氷船は緩い自動延長で港まで進み、物語は必ず完結します
  (描いた部分はそのままの形で航路に残ります)。

## 実装の骨子

| モジュール | 内容 |
| --- | --- |
| `src/game/path.ts` | ストローク→航路: 等距離リサンプル、平滑化、旋回半径制限付き pure pursuit、障害物回避、港への解析的延長(円弧+接線、スパイラル構造的に不可能) |
| `src/game/ice.ts` | 氷原: 変位付き 1 枚プレーン + 永続キャンバスマスク(R=開水面, G=亀裂)。シェーダで雪被覆・青氷・圧力稜線・濡れ縁・暗い海水・空気遠近を描画 |
| `src/game/floes.ts` | 氷片: 非対称多角形 4 種 + 小片の InstancedMesh。船首近傍のみ短時間の傾き/押し分け/沈み込みアニメーション、その後は静的化 |
| `src/game/ships.ts` | 手続き生成の架空中型砕氷船(全長46 m、スプーン型船首、アイスベルト、作業甲板、レーダーマスト、錆流れ)と補給船 |
| `src/game/shipctl.ts` | スプライン追従 + ヨー慣性、控えめなバンク、heave、乗り上げ→荷重→破砕のバイトサイクル、砕氷トリガ |
| `src/game/camera.ts` | 入力中固定俯瞰 → 後方3/4追従 → 最初の厚い氷だけ横からの接写(1回) → 中盤追従 → 高所広角フィナーレ → 接岸クレーン。すべて連続移動でカットなし |
| `src/game/port.ts` | 遠隔地の小港(桟橋・小屋・クレーン・燃料タンク)、岩礁、アザラシ、荷降ろしアニメーション |
| `src/game/sky.ts` | 空ドーム、低い雲、舞う雪、低い太陽光 |

技術要件: WebGL 2 で全ループ成立 / DPR 上限 2 + 内部解像度上限 240 万 px /
一指のみで完結(2 本目の指は無視、カメラジェスチャーなし) / 画面回転後も航路・破砕・船位置を維持。

砕氷船のデザインは実在の沿岸用砕氷船の一次情報(スプーン型船首と低い船首角、
乗り上げた自重による曲げ破壊、幅広船体、砕氷片を舷側へ逃がす船型、喫水線の強化帯)を
参考にした架空のもので、特定組織の塗装・標識は使用していません。

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # 型検査 + production build (dist/)
node tools/verify.mjs   # ヘッドレス実プレイ検証 + 端末別スクリーンショット (shots/)
```

`tools/verify.mjs` は Playwright + ヘッドレス Chromium で実際にプレイし、
直線・緩い右・緩い左・大きなS字・短く速い線・長くゆっくりの線の 6 種で
「右が左に反転しない」「瞬間回転しない」「水路中心線が開通する」「26 m 横の氷は残る」
「補給船が接岸する」「リプレイで前回の氷片が残らない」などを検証し、
iPhone/iPad の縦横 4 構成でスクリーンショットを保存します。
