# 素材研究所 (Material Lab)

スノードームの「中身」を入れ替えて、ふった時としずんだ時の世界の違いを
手で確かめる、4歳児向けのモバイル Web ゲームです。
文字を読まなくても遊べます。数値も、採点も、説明文もありません。

## 遊び方(一本指だけ)

1. 机の上に並んだ**瓶を押す** → 何の粒かは瓶の中身で分かる
2. **押しつづける** → 瓶が傾いて粒がドームに落ちていく
3. **液体の瓶を押す** → **押しつづける** → 液が満ちる
4. **フタを押す** → ドームが閉じる
5. **左右に指をすべらせる** → ふる
6. **まう / しずむ** を眺める → 気に入ったら**棚のボタン**で保存
7. iPad の横画面では**2つ並べて見くらべ**られる

迷って手が止まると、瓶がひとりでに少し傾いて「ここだよ」と教えます。
どの工程でも、次に触る場所には輪と指が出ます。

## 素材(8種)

| 素材 | 形 | 舞い方 | しずみ方 | 光り方 |
|---|---|---|---|---|
| こなゆき | ごく小さい粒・300個 | 水流にすぐ乗って広がる | いちばん遅い | ほとんど光らない |
| ぼたん雪 | 六花・95個 | 大きくひらひら回る | ゆっくり | わずか |
| 金ラメ | 薄い金属片・230個 | ほとんど流されず落ちる | 速い | 面が正対した一瞬だけ強く瞬く |
| 虹の星 | 五角の星・72個 | くるくる回りながら漂う | 中くらい | やわらかく光る |
| はなびら | 曲面の花弁・58個 | いちばん大きく滑空する | とても遅い | 光らない |
| ハート | 砂糖菓子の質感・62個 | くるりと転がる | やや速い | 光らない |
| あわつぶ | 透明な球・80個 | **浮き上がる** | 天井に集まる | 縁がわずかに光る |
| 星のすな | 粗い粒・280個 | まっすぐ落ちる | いちばん速い | ときどきちらつく |

積もり方も素材ごとに違います。すなは急な山、こなゆきは平ら、
はなびらはふんわりと厚く重なります。

## 液体(4種)

| 液体 | 落ち方 | 渦の続き方 | 見た目 |
|---|---|---|---|
| さらさら | いちばん速い | すぐ止まる | ほぼ透明 |
| ふつう | 標準 | 標準 | わずかに青緑 |
| とろり | ゆっくり | いつまでも回る | 琥珀色・粒に尾を引く |
| しゅわしゅわ | 中くらい | 標準 | 泡が立ちのぼり、粒が浮き沈みする |

## 動かす

静的ファイルだけなので、どんな静的サーバでも動きます。

    npx http-server -p 8123 -c-1 .
    # → http://localhost:8123/

## 確認する

    node tools/verify.mjs                 # iPhone/iPad 相当の縦横4画面で全工程を実際に操作する
    ONLY=ipad-landscape node tools/verify.mjs   # 1画面だけ
    node --input-type=module -e "..."     # tools/matrix.html は素材×液体の一覧を描く

CPUの少ない環境では、4画面を続けて動かすとブラウザ同士が食い合って
コマ落ちし、待ち時間が伸びます。1画面ずつ `ONLY=` を付けて回すと安定します。

`tools/verify.mjs` は Playwright で起動し、素材選択 → 注入 → 液体 → フタ →
ふる → 観察 → 保存 → 棚 → 比較 までを実際にクリックとドラッグで通します。
各工程のスクリーンショットとフレーム率が出力されます。

## 構成

    index.html          画面はキャンバス1枚だけ
    src/materials.js    素材と液体のパラメータ(このゲームの中身)
    src/particles.js    球の中の3Dシミュレーション、積もりの高さマップ
    src/sprites.js      粒のスプライト生成(形・回転・反射)
    src/dome_render.js  ガラス・液体・ミニチュア・台座
    src/scene.js        工房の遠景/中景/近景
    src/camera.js       工程ごとの構図
    src/ui.js           瓶・ボトル・ボタン・記号・指の合図
    src/render.js       描画の組み立て
    src/game.js         状態遷移と入力
    src/audio.js        合成音のみの小さな効果音
