# はじめて音になる、オルゴール工房

4 歳児が「音の出ない仕掛けを、自分で音が出るようにする」モバイル Web ゲームです。
主役はシリンダー式オルゴールの **噛み合い調整**。

起動すると、机の上に未調整のメカが出ています。保持ねじは既に緩んでいます。
シリンダーのピンは櫛歯の少し手前を **空振り** しています。

1. 手前の大きな調整つまみ (ローレットドラム) を転がすと、奥の櫛歯ブロックが
   シリンダーへ近づきます。
2. 試し回しハンドルを回すと、ピンが歯を押し、たわんだ歯が外れて戻った瞬間に
   音が出ます。
3. 噛み合ったら、ねじ回しで固定ねじを締めます。
4. そのまま回すと、その小さな発音が続いて短い旋律になります。

調整は「音が出るかどうか」に効きます。**どの音が出るか** は歯ごとに決まっていて、
調整では一切変わりません (調律とは別の工程だからです)。

## 動かす

必要なもの: Node.js 20 以上。

```sh
npm install
npm run dev          # http://127.0.0.1:5173/ を開く
```

本番ビルドと確認:

```sh
npm run verify       # 型検査 → 単体テスト → ビルド
npm run preview      # http://127.0.0.1:4173/ でビルド済みを確認
```

画面証拠 (Playwright / Chromium) の取得:

```sh
npm run preview &    # 別ターミナルでも可 (evidence が自動起動もします)
npm run evidence     # docs/evidence/ に画像が残る
```

同梱の Chromium を使います。`npx playwright install` は不要です。別の場所の
Chromium を使うときは `CHROMIUM_PATH=/path/to/chrome npm run evidence`。

音は最初の指の操作から鳴りはじめます (ブラウザの規約どおり)。右上の ♪ で消音でき、
消音中も接触と解放が画面で分かります。

## 中身

| 場所 | 何が入っているか |
| --- | --- |
| `src/core/spec.ts` | 作中設計の記録。寸法・許容域・調整倍率。実測値ではありません。 |
| `src/core/mechanics.ts` | 空振り / 接触 / たわみ / 解放の判定。純粋関数だけ。 |
| `src/core/song.ts` | 歯の調律とピン配置。短い自作旋律。 |
| `src/core/state.ts` | 噛み合い量・曲の位相・ねじの状態。 |
| `src/audio/engine.ts` | 解放イベントからだけ鳴る発音。BGM タイマーはありません。 |
| `src/view/` | 実ジオメトリの機構、作中治具、材質と光、構図。 |
| `src/input/controls.ts` | 一指の Pointer Events。 |
| `tests/` | 検収項目の単体テスト。 |
| `e2e/` | 実際のポインタ操作での検収と画面証拠。 |
| `STATUS.md` | 確認結果・簡略化・未確認事項。 |
