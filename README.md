# かいたいヤード — 破壊球モバイルWebゲーム

営業停止済みの解体訓練ヤードを舞台に、クレーンから吊られた鋼の破壊球を
**一筆のスワイプ**で引いて放し、解体用試験壁を崩す幼児向け 3D ゲームです。
iPhone / iPad の Safari（縦・横どちらでも）を主対象にしています。

## 遊びかた

1. 球の近くに触れて、壁と反対側（画面手前）や斜めへ一筆で引く
2. 指を離すと、球は重力と慣性で振り子運動に移り、壁へ向かう
3. **どこへ・どれだけ引いたか**で結果が連続的に変わる
   - 横方向の差 → 振り子の面が傾き、衝突位置が左右に変わる
   - 引き量 → 振幅と衝突速度が変わり、崩れる量が変わる
   - 途中の大きな曲線 → 振れる面へ穏やかに反映される
   - 細かな指の震えはローパスフィルタで吸収される
4. 初回のみ、球が小さく引かれて放たれる無言の見本が一度だけ再生される
5. 壁が大きく崩れると絵のパネルが開き、同じ壁の再挑戦か別材質を選べる
   （右上の丸ボタンからいつでも開ける）

得点・時間制限・失敗はありません。外れても球は地面近くで砂埃を上げ、
軌跡の結果が必ず見えます。

## 材質ごとの崩れかた

| 材質 | 崩れかた |
| --- | --- |
| レンガ | 目地に沿った局所的な割れ。レンガ片とモルタルの粉塵。低エネルギーでも欠けやすい |
| 中空ブロック | まず外殻が欠けて内部空洞が現れ、板状片が落ちる。二段階破壊 |
| 鉄筋コンクリート | 弱打は表面の欠けと放射状のひび（蓄積する）。強打で重い塊が抜け、縁に鉄筋が残る |

衝突点から破壊が始まり、支持を失った上部が一拍遅れて連鎖的に落ちます。
穴と瓦礫は次の一撃でも維持され、画面回転後も残ります。
崩れた壁の奥には、もともと存在した旧工場の鉄骨フレームと古い壁画が現れます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型検査
npm run build      # 型検査 + 本番ビルド
```

## 実装メモ

- TypeScript + Three.js (WebGL 2) + Vite。物理エンジンは使わず、目的特化の軽量実装
  - 球＋ロープ: 球面振り子（ロープ長拘束、ドラッグ中は弧上のターゲットへの減衰スプリング）
  - 破片: プール化した剛体（重力・転がり・地面衝突・スリープ）。静止片は粗いハイトフィールドへ体積を積み、後続の破片が山に堆積する
  - 壁: 事前分割されたユニット群（InstancedMesh）。衝突エネルギー→破壊半径の連続写像＋HP蓄積＋下支え判定による遅延崩落
- 入力は Pointer Events。ストロークを（振幅角・方位角）の連続値として弧上へ投影し、
  約10Hzのローパスで手ぶれを除去。左右の対応はカメラの右ベクトルから決まるため、
  画面上で球は常に指の左右へ追従する
- スワイプ中はカメラ固定。衝突後のみ低い視点へ寄り、自動で戻る（衝突直前のカットなし）
- 音はすべて WebAudio による合成（油圧アイドル、ロープの軋み、風切り、材質別衝撃音、
  遅れて落ちる破片、粉塵の沈静）。爆発音・コミカル音は不使用
- 品質はデバイス能力（WebGPU の有無・メモリ）で段階化し、フレームが重い場合は
  描画解像度を自動で下げる。破片は影を落とさず、影は主要物のみ
