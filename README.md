# つるつるアイスカー

4歳児向けのモバイルWebゲーム。傷だらけの屋内アイスリンクに、子どもが**一筆**で走行経路を描くと、架空の**電動アイスリサーファー**がその線を現実的な旋回半径で走り、機体後方のconditionerが通った幅だけが「傷と雪粉のある氷」から「薄い水膜を持つ滑らかな氷」へ変わります。最後に、待っていたスケーターがその道を滑ります。

実在メーカー(ZAMBONI等)の名称・ロゴ・機体輪郭・カラーリングは一切使用していない、機能設計から起こした架空車両です。

## 遊び方

- 説明文なし。イントロ(荒れた氷の接写 → 待つスケーター → conditionerを下ろす動作 → リンク奥を向く構図)が目的を伝えます。タップでスキップ可能。
- 車両からスケーターへ向けて指で一筆描くと、車両が走り出します。
  - 縦画面: 下から上へ / 横画面: 左から右へ(カメラが持ち替わります)
- ゲームオーバー・時間制限・採点・衝突罰はありません。短い線でも必ず帯ができ、塗り残しは次の一筆で追加整氷できます。
- 右下の ↺ で最初からやり直し(氷が初期状態に戻ります)。

## 車両の機能設計(架空・電動)

一次的に公知のアイスリサーファーの構成(削氷刃 → 水平オーガー → 垂直オーガー → 雪タンク / 洗浄水散布・回収 / 製氷水をタオルで均す)に基づき、次を備えます:

- 運転席(オープンキャブ、運転手、操舵と連動するハンドル)
- 製氷水タンク・洗浄水タンク(給水口2つ・水位ゲージ・給水口周りの汚れ)
- 前方の雪タンク(開放ビン+蓋。走行で雪が溜まり、初回クリア後に蓋を開けて確認)
- 後部conditioner(ステンレス筐体、削氷刃、水平オーガー、洗浄水スプレーバー、製氷水配管、後端タオル)
- 外部配管: conditioner→雪タンクの垂直オーガーシュート、車体→conditionerの洗浄水/製氷水ホース
- スタッド付き氷上タイヤ、バッテリーハッチ+充電ポート(排気管なし)

内部機構は常時透視しません。稼働はオーガー回転・シュート振動・雪煙・湯気・音で示します。

## 実装

- **WebGL 2 + three.js + Vite**。単一の氷面メッシュ+GPUマスク(1024²のピンポンRT)。conditionerの実幅ぶんの帯を走行軌跡へスタンプし、normal / roughness / snow / wetness を同一面のシェーダで連続更新。水膜は別平面を重ねず、同一面のパラメータ(数秒で落ち着く減衰つき)。
- 経路: pointer軌跡を等間隔リサンプリング → 微細な揺れのみ平滑化 → ボードからのマージンへクランプ → 最小旋回半径(3.8m)まで曲率緩和。速度は入力速度を穏やかに反映(1.1〜3.1 m/s、カーブで減速)。
- 車両: 後軸基準の自転車モデル+pure pursuit(lookahead)。線への瞬間吸着はしない。conditioner帯は後軸のさらに後方から生成。
- カメラ: 入力中は固定俯瞰(カメラ操作と描画は同一指に割り当てない)。走行中は 高俯瞰 → conditioner接写(氷が変わる瞬間はカットしない)→ 斜め後方 → 広角 → スケーター追従、をダンピング付きで連続移動。
- 音: WebAudioによる全合成(電動モーター、刃の削り音、オーガー、水、油圧、チャイム)。
- スクロール防止(`touch-action:none` ほか)、入力線は指のわずかに先まで表示。
- 内部解像度は devicePixelRatio ≤2 かつ総ピクセル上限でキャップ。

## 開発

```bash
npm install
npm run dev       # 開発サーバ
npm run build     # production build → dist/
npm run preview   # http://127.0.0.1:4173
```

## テスト

Playwright(実ポインタ操作)による必須テスト一式:

```bash
npm run preview &
node tests/full.mjs      # 9種のジェスチャ + 物理不変条件 84チェック
node tests/devices.mjs   # 4端末寸法 × (走行前/走行中/接写/完成) スクリーンショット
```

検証内容: 帯が車両前方に出ない / 水膜が通過前に現れない / 帯幅がconditioner幅(2.2m)と整合 / 左右の膨らみ・S字が帯に残る / 瞬間吸着なし / 壁際で穏やかに離れる / 縦横回転後の続行 / 再プレイでマスク初期化、ほか。スクリーンショットは `screenshots/` 以下。
