# おかえり、深海へ

4歳児向けのモバイルブラウザゲーム。魚を釣り上げるのではなく、**深海の魚をやさしく元の深さへ帰してあげる**ゲームです。勝ち負けも失敗もありません。あるのは、安心・回復・再会、そして下へひらけていく海の旅だけです。

## 起動方法

依存ライブラリはありません。`index.html` 1ファイルで完結しています。

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → iPhone / iPad / PC のブラウザで http://<ホスト>:8000/ を開く
```

`file://` で直接開いても動作しますが、iOSでは http 経由を推奨します。縦画面・横画面のどちらでも遊べます。音はWebAudioでリアルタイム合成されます(最初のタップで有効化)。

## 遊びかた(ことばはいりません)

1. 船縁のそばで、器具にやさしく抱えられた魚が水面で待っています
2. **タップ** … 器具の留め具がとまり、じゅんびかんりょう
3. **下へスワイプ** … 降下がはじまります。水面を抜け、明るい表層から青い中層、暗い深層へ
4. 深く潜るほど、魚は少しずつ落ち着いていきます
5. 住みかの近くで留め具がひらき、魚は自分の力で泳ぎだします。小さな魚たちが迎えにきます
6. 泡のボタンをタップすると、次の魚が待っています

降下中にもう一度下スワイプすると、すこしだけ速く降りられます。降ろしすぎ・遅すぎ・早すぎはミスになりません。

## 実装済みループ

- 深海帰還ループ(準備 → 降下 → 水面突破 → 減光 → 解放 → 自力遊泳 → 再会 → 次の魚)
- 魚3種: キンメダイ / メバル / ハタ(体色・眼・ひれ・体型・模様が個別、深度で色が沈む)
- 深度4段: 表層(泡・コースティクス・光条)/ 中層(青の深まり・マリンスノー・クラゲや小魚の群れ)/ 深層(減光・発光プランクトン)/ 海底近傍(地形と生きもの)
- 海底環境3種: 岩礁(ヤギ類・岩)/ 砂底(ウミエラ・ヒトデ・砂紋)/ 海綿の庭(カイメン・ソフトコーラル・イソギンチャク)
- 縦横両対応のレール型カメラ(降下前は静止、降下中は追従+接写⇄引きの台本)
- WebGLシェーダによる海(空〜水面〜深海の連続グラデーション、神光、コースティクス、浮遊粒子、ビネット)
- WebAudioによる環境音の合成(波、潜行に伴うこもり・深海パッド、水しぶき、泡、解放のチャイム)
- 文字を使わない誘導(波紋+下向きシェブロン、ゴーストハンドの下スワイプ、泡ボタン)

## デバッグ用URLパラメータ

- `?ts=3` … シミュレーション速度倍率(検証用)
- `?dpr=1` … 描画解像度の上限(低速なGPU/ソフトウェアレンダリング用)

`window.__game` に状態(state / frac / level)と操作(tap / swipe / warp)を公開しており、自動試遊テストが `scratch` 側の Playwright スクリプトから利用します。

## 既知の制約

- WebGL非対応環境ではCanvas 2Dグラデーションの簡易背景にフォールバックします(粒子・光条なし)
- 効果音はすべて合成音のため、実録音ベースの環境音より簡素です
- 端末の回転には追従しますが、回転の瞬間はカメラが1秒ほどかけて再構図します
