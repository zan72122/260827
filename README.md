# サンタのえんとつ (Santa's Chimney)

4歳児向けのモバイルWebゲーム。太ったサンタと大きな袋が、身体を柔らかく変形させて狭い煙突をスルルルッと通り抜ける——その一点を中心に設計した、2〜4分のクリスマス配達体験です。文字による説明・得点・時間制限・失敗はありません。

## 遊びかた(すべて一本指)

1. そりが屋根に着地し、サンタが袋を担いで煙突へ歩く
2. サンタが煙突を覗き込んで誘う —— **下へスワイプ**すると身体と袋が圧縮されて煙突へ入る
3. スワイプの速さで滑り方が変わる(ゆっくり=コロコロ、速い=煤が舞う)。指を止めれば止まり、上へスワイプすれば登り直せる。左右で壁に寄りかかる
4. 暖炉に着地 → ヒゲの煤を払う → 3つの贈り物を**タップ**して靴下へ(形の順に下から膨らむ)
5. 鼻の横に指 —— 顔を**タップ** → **上へスワイプ**でシュンッと逆上昇
6. 屋根へ戻り、絵のメニューで「同じ家」「別の煙突」「自由に上下」を選択

煤の跡は毎回少しずつ違う形で煙突に残り、次の滑走でも消えません。画面を回転しても進行・煤・靴下の中身は保持されます。

## 技術構成

- **Vite + TypeScript + Three.js** (WebGL2 / モバイルSafari対応)
- 外部アセットなし: 全テクスチャ(煉瓦・布・毛皮・雪・木・編地)はCanvas 2Dでプロシージャル生成
- サンタは階層ボーンリグ + 非一様スケールによる連続圧縮変形(morphではなく制御可能なbone deformation)
- 屋根・煙突断面・部屋は単一の連続ワールド。カメラはauthoringされたショット間を減衰補間で移動し、カットなし
- 煙突移動はスワイプでスクラブするauthoredパス(自由物理なし)
- 煤跡はCanvasテクスチャへの動的ペイント、雪跡はtrailジオメトリ、煤・雪はプールされたbillboardパーティクル
- 靴下はリング変形メッシュ(贈り物の形・順序で膨らみが変わる)
- 動的解像度スケーリング(fps監視でpixelRatio段階降格、低品質時は影を無効化)
- 音はWebAudioで合成(アセットなし)。初回タッチでアンロック

## 開発

```bash
npm install
npm run dev        # 開発サーバー (http://localhost:5173)
npm run typecheck  # 型検査
npm run build      # 本番ビルド (dist/)
```

### 自動テスト(要 Chromium)

```bash
node tools/drive.mjs --device=iphone-p --flow=full   # 全ループ自動プレイ+スクリーンショット
node tools/audit.mjs --device=ipad-p                 # 回転保持・自由モード・別の家の監査
```

`?debug=1` を付けるとローカル計測(最初の入力時刻、最初の下降成功、ヒント回数、再試行)のオーバーレイが表示されます。計測は `localStorage` のみで外部送信はありません。
